Configure the default window size for Visu(AL)-1 depending on your display resolution.

**Currently only supported for 3D Visualiser.**

Size 1: Use this for 800x600 displays. Preview panels will be sized to 560x420.
Size 2: Use this for 1024x768 displays. Preview panels will be sized to 720x540.
Size 3: Suitable for displays 1280x720 or larger. 2D image processing panel will be sized to 800x600, and 3D graphics has no theoretical limit.
Size 4: Enable high-definition image previews for 2D image processing; preview panel will be sized to 1200x900. Warning: Higher memory load and requires a 1920x1080 or larger display.
